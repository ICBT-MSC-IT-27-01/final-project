## 8.1 Research Summary

The project developed an AI-driven prototype for weather forecasting and crop recommendation in Anuradhapura District. It combines a Python LSTM weather model, ASP.NET Core backend, SQL Server database and Angular frontend.

## 8.2 Achievement Of Work

The implementation achieved the approved technical scope: seven-day weather forecasting, operational forecast provenance, read-only recommendation evaluation, role-based access, Agricultural Officer review workflow, administrator configuration foundations and browser-tested frontend workflows.

## 8.3 Contributions

The main contributions are a reproducible weather forecasting pipeline, explainable weighted crop suitability framework, clear separation between weather prediction and recommendation scoring, and a role-based prototype suitable for MSc evaluation.

## 8.4 Limitations

The system should not be presented as production-ready. Real participant UAT and Agricultural Officer expert validation were not performed. Ethics approval remains pending. Scientific agronomic validation is partial, and operational predictive accuracy is not independently verified.

## 8.5 Future Work

Future work should include ethics-approved UAT, qualified Agricultural Officer review, validated seven-day or stage-aware crop thresholds, longitudinal operational forecast evaluation, ERA5/Open-Meteo source compatibility analysis, deployment hardening and improved local soil-data workflows.

## 8.6 Final Conclusion

The project provides a defensible, technically validated MSc prototype. Its strongest claim is technical integration and explainability. Its scientific and practical claims should remain cautious until further expert, participant and operational validation is completed.
