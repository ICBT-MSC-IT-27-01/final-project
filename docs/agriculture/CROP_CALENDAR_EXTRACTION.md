# Crop Calendar Extraction

The DoA [crop-calendar index](https://doa.gov.lk/naicc-publications-crop-calender/) was used only to locate the individual artifacts below. Each listed artifact was downloaded and visually inspected on 2026-10-17; these are one-page image calendars, not unreviewed index links.

| Crop | Inspected artifact and extracted content | Applicability and limits |
|---|---|---|
| Paddy | Dry/Intermediate irrigated calendar; activity lanes for 2.5, 3 and 3.5 month crops; note to select variety for Maha/Yala. The rainfed calendar is separately available. | Dry/Intermediate Zone. It establishes irrigation conditions and calendar context, not numeric seven-day weather thresholds. |
| Maize | Dry Zone calendar explicitly lists Anuradhapura District and shows rainfed/irrigated production columns. | Applicable calendar context; no numeric seven-day weather rule extracted. |
| Green Gram | Dry Zone calendar explicitly lists Anuradhapura; varieties MI-5/Ari 60-65 days, Harsha 55-60, MI-6 55-58; mid-season cultivation 60 days. | Crop-duration context only; no numeric weather rule. |
| Cowpea | Dry Zone calendar explicitly lists Anuradhapura; MI-35 65-80 days, Dhawala 60-70, Waruni 55, Bombey 75-90, MICP 60-70. | Crop-duration context only; no numeric weather rule. |
| Groundnut | Intermediate & Dry Zones calendar includes Anuradhapura DL-1d. | Geographic context only; no numeric weather rule extracted. |
| Chilli | Dry Zone calendar explicitly lists Anuradhapura; includes seasonal activity lanes and drought/heavy-rain management notes. | Applicable calendar context; no numeric seven-day weather rule extracted. |

Publication metadata visible on the calendars is Department of Agriculture Sri Lanka / AFACI, generally 2013; the inspected irrigated paddy artifact is 2015. Calendar information supports crop context and source disclosure. It is not treated as a scientifically validated weather-suitability threshold or an invented sowing-date rule.
