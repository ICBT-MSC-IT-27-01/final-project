# Anuradhapura AI Codex Skill

This bundle contains one reusable Codex skill for the MSc project.

Contents:
- `SKILL.md` — skill manifest and operating rules
- `references/project-specification.md` — full approved development specification
- `references/reference-file-timing.md` — when to provide dissertation/diagram reference files
- `assets/phase-task-template.md` — reusable phase prompt checklist

The folder can be provided directly as a skill directory, or zipped as a single top-level folder for environments that support skill bundle upload.
